# SNI Spoofing Config Modifier

### Overview

This project is a simple PyQt5-based tool for editing and transforming V2Ray configuration links. It supports common proxy protocols such as VLESS, VMess, Trojan, and Shadowsocks.

The main purpose of the tool is to make it easier to batch-edit configs, decode Base64 subscription links, and quickly adjust basic connection parameters like host, port, and SNI.

It can also prepare configurations for use in SNI spoofing-related workflows in the broader ecosystem of this project:

👉 https://github.com/patterniha/SNI-Spoofing
